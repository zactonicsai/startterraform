Linux Admin Guide

Welcome to Red Hat Linux!

Imagine your computer server is a giant factory. Red Hat Enterprise Linux (RHEL) is the manager keeping the lights on, the doors locked, and the workers doing their jobs. As an Administrator, your job is to give this manager the right instructions to keep everything running smoothly.

1. Common Admin Tasks

A. Managing Users

What: Creating accounts so different people can log into the server.

Why: You never want everyone sharing one master password. That's a huge security risk!

How: Use the useradd and passwd commands.

# Create a new user named "sarah"
sudo useradd sarah

# Give Sarah a password
sudo passwd sarah

B. Managing Services

What: Starting and stopping background programs (like a web server).

Why: If a website crashes, you often just need to restart the program that runs it.

How: Use the systemctl command.

# Restart the web server
sudo systemctl restart httpd

# Make sure the web server starts automatically when the computer turns on
sudo systemctl enable httpd

2. Key Troubleshooting

When things break, don't panic. You just need to play detective.

Reading the Diary (Logs)

Linux writes down everything it does in log files. If a program fails, check the diary!

# Read the main system log
sudo journalctl -xe

Finding Resource Hogs

Is the server super slow? Find out which program is eating all the memory.

# Show a live list of running programs
top

3. Pros, Cons, and Gotchas

  • Pro: Super stable. You rarely have to reboot a Linux server unless you update the core kernel.
  • Pro: Free and open-source tools mean you can build almost anything without buying expensive software.
  • Con: It is mostly text-based (Command Line). There is no mouse to click around with on a server!
  • Gotcha - SELinux: Red Hat has a very strict security guard built-in called SELinux. If you configure a web server perfectly and it still doesn't work, SELinux probably blocked it.
    Quick check command: getenforce

4. Automation Scripts

Administrators are lazy in a good way—they write code to do their chores for them.

Bash Shell Script (Automated Backup)

Shell scripts are just a list of terminal commands saved in a text file. This script zips up your website folder.

#!/bin/bash
# Step 1: Tell the user what we are doing
echo "Starting website backup..."

# Step 2: Zip the folder (c=create, z=zip, v=verbose/show me, f=filename)
tar -czvf /backup/website_backup.tar.gz /var/www/html

# Step 3: Finish up
echo "Backup is complete!"

Python Script (Check Hard Drive Space)

Python is great for logic and math. This script warns you if your hard drive is getting full.

import shutil

# Get hard drive stats for the main folder ("/")
total, used, free = shutil.disk_usage("/")

# Convert bytes to Gigabytes (GB)
free_gb = free // (2**30)

print(f"You have {free_gb} GB of free space left.")

if free_gb < 10:
    print("WARNING: Disk is almost full! Clean up your files.")
else:
    print("Disk space looks healthy.")

5. Awesome Packages to Load

You can install these open-source tools using Red Hat's package manager, dnf.

  • epel-release: The "Extra Packages for Enterprise Linux" vault. Always install this first to unlock hundreds of free tools! sudo dnf install epel-release
  • htop: A beautiful, colorful version of the standard top command. It makes reading computer memory and CPU usage super easy.
  • tmux: Lets you split your single black terminal screen into multiple boxes so you can do three things at once.
  • tldr: Standard manual pages are too long. "Too Long; Didn't Read" gives you the 5 most common examples of any command instantly.

What is SELinux?

Security-Enhanced Linux is like an internal police force inside the computer.

Normal Linux permissions say: "Can this user read this file?"
SELinux goes further and says: "Is this Web Server program even ALLOWED to look at files in this specific folder?"

Admin Tip: During the exam, never permanently turn SELinux off! You will fail immediately. You must learn to fix the labels instead.
